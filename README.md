# Mandal-hardware-and-paints

This repository now contains a simple GitHub Pages site with:

- index.html (homepage)
- products.html (product gallery)
- video.html (shop video page)
- assets/css/style.css

Place your shop images in /assets/images/ with these filenames to display them on the site:
- product1.jpg (e.g., Wallcare bags)
- product2.jpg (e.g., UltraTech Tilefix)
- storefront.jpg (shop sign / exterior photo)

Place a shop video at /assets/video/shop.mp4, or send a YouTube/Vimeo link and I'll embed it.

If you want, reply with "Create promo" and I will auto-generate a short promotional video from the images and add it to the site.
